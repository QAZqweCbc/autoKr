# 删除逻辑升级说明

## 问题描述

用户在注册账户时提前收到了触发删除邮箱的请求，当时邮箱注册流程还没有完成，导致删除先执行了，从而 token 或其他存储用户信息的地方还残留账号信息。

## 解决方案

### 1. 数据库升级

新增三个字段到 `client_users` 表：

- `registration_status` - 注册状态：
  - `pending` - 待开始
  - `in_progress` - 进行中
  - `completed` - 已完成

- `pending_delete` - 预删除标记（布尔值）
  - `TRt_users
ADD COLUMN registration_status ENUM('pending', 'in_progress', 'completed') DEFAULT 'completed';

ALTER TABLE client_users
ADD COLUMN pending_delete BOOLEAN DEFAULT FALSE;

ALTER TABLE client_users
ADD COLUMN registration_started_at BIGINT NULL;

ALTER TABLE client_users
ADD INDEX idx_pending_delete (pending_delete);

UPDATE client_users SET registration_status = 'completed' WHERE registration_status IS NULL;
```

### 2. 升级后的删除逻辑

#### 命令行删除工具 (`delete-user.js`)

```bash
node delete-user.js email@example.com
```

**新行为：**

- ✅ **注册已完成** → 立即删除用户
- ⏳ **注册进行中** → 标记为预删除，等待注册完成后自动删除

#### 程序化删除（TypeScript API）

```typescript
import { deleteClientUser } from './services/client-user.service'

const result = await deleteClientUser('email@example.com')

if (result.deleted) {
  console.log('✅ 用户已删除')
} else if (result.pending) {
  console.log('⏳ 已标记为预删除，将在注册完成后删除')
}
```

### 3. 注册流程自动检查

注册完成时，系统会自动：

1. 将 `registration_status` 更新为 `completed`
2. 检查 `pending_delete` 标记
3. 如果标记为 `TRUE`，立即删除该用户

**在注册完成后调用：**

```typescript
import { markRegistrationCompleted } from './services/client-user.service'

// 注册成功后
const wasDeleted = await markRegistrationCompleted(email)

if (wasDeleted) {
  console.log('⚠️ 用户已被预删除标记删除')
  // 不要继续后续操作
}
```

## 技术细节

### 状态转换流程

```
注册开始
  ↓
registration_status = 'in_progress'
pending_delete = false
  ↓
[用户可能在此期间被标记删除]
  ↓
pending_delete = true (如果收到删除请求)
  ↓
注册完成
  ↓
registration_status = 'completed'
  ↓
检查 pending_delete
  ↓
如果 = true → 立即删除
如果 = false → 正常完成
```

### API 函数

#### `markRegistrationCompleted(email: string): Promise<boolean>`

标记注册完成并检查预删除。

**返回值：**
- `true` - 用户已被删除
- `false` - 用户正常完成注册

#### `deleteClientUser(email: string): Promise<{deleted, pending, message}>`

删除用户（带注册状态检查）。

**返回值：**
```typescript
{
   boolean,    // 是否已删除
  pending: boolean,    // 是否标记为预删除
  message: string      // 操作说明
}
```

## 注意事项

1. **必须先执行数据库迁移**才能使用新功能
2. **现有用户**会自动标记为 `completed` 状态
3. **新注册用户**从 `in_progress` 开始
4. **预删除标记**不会影响用户登录，但会在注册完成后删除
5. **建议**在注册完成后立即调用 `markRegistrationCompleted`

## 回滚方案

如果需要回滚到旧版本：

```sql
-- 移除新增字段
ALTER TABLE client_users DROP COLUMN registration_status;
ALTER TABLE client_users DROP COLUMN pending_delete;
ALTER TABLE client_users DROP COLUMN registration_started_at;
```

并恢复 `delete-user.js` 到之前版本。
