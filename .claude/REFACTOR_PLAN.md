### 3. 修复三层嵌套异常覆盖 ⏱️ 6h
**问题**: `auto-refresh-optimized.service.ts:649-767` 三层嵌套导致错误信息丢失

**当前结构**:
```typescript
try {
  // 第一层：主刷新逻辑
  try {
    // 第二层：OIDC重试
    try {
      // 第三层：SSO重新认证
    } catch (e3) {
      // 错误3被覆盖
    }
  } catch (e2) {
    // 错误2被覆盖
  }
} catch (e1) {
  // 只记录最后一个错误
}
```

**修复方案**:
```typescript
const errors: Error[] = []

// 尝试主刷新
try {
  return await mainRefresh()
} catch (e1) {
  errors.push(e1)
}

// 尝试OIDC重试
try {
  return await oidcRetry()
} catch (e2) {
  errors.push(e2)
}

// 尝试SSO重新认证
try {
  return await ssoReauth()
} catch (e3) {
  errors.push(e3)
}

// 统一抛出所有错误
throw new AggregateError(errors, 'All refresh attempts failed')
```

**影响范围**: 错误信息丢失、调试困难
