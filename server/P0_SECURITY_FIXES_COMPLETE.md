## ⚠️ 重要提示

### 对于开发者

1. **不要提交 .env 文件**
   - 已添加到 .gitignore
   - 只提交 .env.example

2. **密钥管理**
   - 开发和生产使用不同的密钥
   - 定期轮换密钥
   - 不要在代码中硬编码

3. **CORS配置**
   - 开发环境可以包含 localhost
   - 生产环境只包含实际域名
   - 不要使用 `*` 通配符

4. **认证令牌**
   - 默认过期时间7天
   - 使用 HTTPS 传输
   - 实现令牌刷新机制

### 对于前端开发者

1. **获取令牌**
   - 通过登录接口获取
   - 存储在 localStorage 或 sessionStorage
   - 不要存储在 cookie（除非使用 httpOnly）

2. **使用令牌**
   - 在所有API请求中添加 `Authorization: Bearer <token>`
   - 处理401错误（跳转到登录页）
   - 处理403错误（显示权限不足）

3. **令牌刷新**
   - 监听401错误
   - 实现自动刷新机制
   - 刷新失败时跳转到登录页
