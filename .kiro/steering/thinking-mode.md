## 问题类型快速判断（3秒决策）

| 类型 | 判断标准 | 处理方式 |
|------|---------|---------|
| **简单询问** | 问候、确认、是/否、纯闲聊 | **直接回答，不走思考流程** |
| **模糊探索问题** | "如何实现X？"（需求不明确）、方案调研 | **探索模式** (5-8步) |
| **中型技术问题** | 功能开发、模块设计、代码重构 | **标准模式** (8-12步) |
| **复杂技术问题** | 系统架构、技术选型、重大重构 | **深度模式** (15-20+步) |

### 判断逻辑
- 包含"报错"、"怎么改"、"为什么不行" → **微型问题**
- 包含"如何设计"、"怎样架构"、"选型建议" → **复杂问题**
- 包含"添加功能"、"重构模块" → **中型问题**

## MCP工具使用规则

### sequentialthinking
- 步数由被路由到的具体思考模式动态决定
- 不再固定20步，根据问题复杂度调整

### memory/filesystem
- 在**标准模式**和**深度模式**中，优先调用以获取上下文
- 调用前向用户简要说明目的
- 优先使用批量读取避免多次交互

---

## 输出要求

每次回答必须包含：

1. **模式声明**（开头）
   ```
   【问题类型】XXX
   【思考模式】XXX模式（X-X步）
   ```

2. **决策透明**
   - 复用决策的理由
   - 方案选择的权衡
   - 关键判断点说明

3. **结论整合**
   - 最终方案或代码
   - 实施步骤
   - 风险提示
